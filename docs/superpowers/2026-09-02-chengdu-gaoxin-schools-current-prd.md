# 成都高新区教育资源地图 PRD

## 1. 文档信息

- 文档类型：当前版本产品需求说明
- 页面名称：成都高新区教育资源地图
- 当前线上地址：https://codeandylau.github.io/chengdu-gaoxin-schools/
- 当前版本基线：2026-09-02 已实现页面
- 适用范围：成都高新区小学、初中及九年一贯制教育资源查阅工具

## 2. 背景与目标

当前页面面向需要快速了解成都高新区义务教育资源分布的用户，提供学校名单、学段、办学性质、片区、地址、电话、资料来源和地图点位信息。

产品目标：

- 帮助用户快速查找成都高新区小学和初中资源。
- 通过分布图辅助判断学校在高新南区、高新西区及各片区的空间密度。
- 明确区分小学登记点、初中对应学校、专项电脑随机录取、民办招生、市直属招生等资料口径。
- 保留资料来源和风险提示，避免把便民整理误读为官方划片或录取承诺。

非目标：

- 不提供官方学区查询结果。
- 不判断用户是否具备入学资格。
- 不承诺点位可直接用于导航。
- 不提供学校排名、升学评价或主观推荐。

## 3. 用户与场景

目标用户：

- 正在了解成都高新区小学、初中资源的家长。
- 关注片区教育资源密度的购房、租房或搬迁决策用户。
- 需要初步整理学校名单、地址和招生口径的研究或咨询人员。

核心场景：

- 用户按学校名称、地址或片区搜索目标学校。
- 用户筛选小学、初中或全部学校，查看对应数量和地图分布。
- 用户筛选公办、民办学校，快速区分资源性质。
- 用户筛选高新南区或高新西区，聚焦区域内资源。
- 用户点击地图点位或学校列表，查看学校详情。
- 用户查看资料来源，回到原始公告或公开资料进一步核验。

## 6. 功能需求

### 6.1 概览统计

当前页面展示五类全局统计：

- 校区总数
- 小学阶段校区数
- 初中阶段校区数
- 公办校区数
- 民办校区数

统计基于全部学校数据计算，不随筛选条件变化。

### 6.2 关键词搜索

用户可以通过输入框搜索学校。

搜索规则：

- 搜索范围包含学校名称、地址、所属区域和片区。
- 搜索会去除首尾空格。
- 搜索对英文大小写不敏感。
- 搜索结果实时更新地图、列表、结果数量和详情默认项。

无结果状态：

- 地图区展示“没有匹配的学校”。
- 列表区展示“暂无匹配结果”，并提示可尝试更换关键词或筛选条件。

### 6.3 学段筛选

支持筛选项：

- 全部
- 小学
- 初中

规则：

- 选择小学时，展示 `stages` 包含小学的校区。
- 选择初中时，展示 `stages` 包含初中的校区。
- 九年一贯制或同时包含小学、初中的校区会同时出现在小学和初中筛选结果中。

### 6.4 办学性质筛选

支持筛选项：

- 全部
- 公办
- 民办

规则：

- 选择公办时，仅展示 `nature` 为公办的校区。
- 选择民办时，仅展示 `nature` 为民办的校区。

### 6.5 区域筛选

支持筛选项：

- 全部
- 高新南区
- 高新西区

规则：

- 按 `area` 字段前缀匹配。
- 区域筛选与关键词、学段、性质筛选同时生效。

### 6.6 筛选联动

筛选结果会同时影响：

- 地图点位
- 地图当前显示数量
- 右侧学校列表
- 右侧结果总数
- 当前详情展示

当前选中的学校不在新筛选结果中时，详情自动切换为筛选结果中的第一所学校。

### 6.7 地图展示

地图为无外部地图服务依赖的 SVG 示意分布图。

当前规则：

- 按经纬度投影到固定 SVG 画布。
- 使用轻微偏移降低点位重叠。
- 背景展示高新西区、高新南区、中和片区、桂溪/石羊片区等区域提示。
- 地图用于资源分布观察，不作为精确导航地图。

点位样式：

| 类型 | 表现 |
| --- | --- |
| 小学 | 蓝绿色描边，点内显示“小” |
| 初中 | 橙色描边，点内显示“初” |
| 一贯制 | 紫色描边，点内使用实心圆 |
| 民办 | 棕橙色描边 |
| 当前选中 | 点位半径更大，描边更粗 |

图例说明：

- 小学
- 初中
- 一贯制
- 民办
- 精确校名匹配数量和总校区数量

### 6.8 地图交互

用户点击地图点位后：

- 阻止默认锚点跳转。
- 更新当前选中学校。
- 右侧详情区同步展示该学校信息。
- 右侧列表对应学校显示选中态。

地图点位带有可访问标签，内容包含学校名称和学段。

### 6.9 学校列表

列表展示当前筛选结果。

每条列表项包含：

- 学校图标
- 学校名称
- 片区
- 学段
- 进入箭头

点击列表项后：

- 更新当前选中学校。
- 详情区同步展示该学校信息。
- 列表项进入选中态。

### 6.10 学校详情

详情区展示当前选中学校信息。

详情字段：

- 学段标签
- 办学性质标签
- 学校名称
- 地址
- 所属区域/片区
- 电话；无电话时显示“公开电话待核验”
- 资料口径
- 特殊备注；仅有备注时展示
- 点位核验状态

图标规则：

- 同时包含小学和初中：楼宇图标
- 小学：学校图标
- 初中：毕业帽图标

### 6.11 资料来源

页面展示 5 项主要资料来源链接：

- 2026 年高新区小学入学登记点
- 2026 年成都高新区小升初划片范围
- 2026 年高新区小升初对应表
- 2026 年成都义务教育入学政策
- 成都美视师一学校 2026 招生简章

点击来源链接后：

- 在新标签页打开原始资料。
- 使用 `rel="noreferrer"` 降低来源页面获取引用信息的风险。

## 7. 非功能需求

### 7.1 响应式布局

当前页面支持桌面和移动端基础适配：

- 大屏使用地图和列表详情双栏布局。
- 中小屏下内容按单列自然堆叠。
- 地图高度在大屏和小屏有不同约束。
- 列表区域支持独立滚动。

### 7.2 可访问性

当前已实现：

- 搜索输入框具备隐藏标签。
- 筛选控件使用 `fieldset` 和隐藏 `legend`。
- 筛选按钮使用 `aria-pressed` 表达选中状态。
- 地图区域和列表详情区域具备 `aria-label`。
- SVG 地图具备 `title`。
- 地图点位具备按学校名称和学段生成的 `aria-label`。
- SVG 点位支持焦点态样式。

### 7.3 性能

当前实现特点：

- 学校数据本地 JSON 加载，无运行时接口请求。
- 筛选逻辑使用 React `useMemo` 根据查询和筛选条件计算。
- 地图使用 SVG，不依赖第三方地图 SDK 或地图瓦片加载。
- GitHub Pages 静态托管，访问成本低。

### 7.4 部署

当前支持两种构建入口：

- OpenAI Sites / Vinext 入口：`app/page.tsx`
- GitHub Pages / Vite 静态入口：`pages/main.tsx`

当前免费公开托管方案：

- 代码仓库：https://github.com/codeAndylau/chengdu-gaoxin-schools
- GitHub Pages：https://codeandylau.github.io/chengdu-gaoxin-schools/

## 8. 当前限制与风险

- 页面不是官方查询系统，所有入学资格、划片和录取结果必须回到教育主管部门公告核验。
- 地图为示意分布图，不是高德、百度或政务地图底图。
- 29 个点位为片区近似定位，仍需后续精确坐标核验。
- 14 个校区电话为空，当前展示为“公开电话待核验”。
- 数据为静态文件，无法自动感知政策公告或学校信息变更。
- 当前筛选条件不会写入 URL，无法直接分享某个筛选后的视图。
- 当前没有学校对比、收藏、导出、导航、距离测算、学区边界图层等能力。
- 当前没有后台管理界面，新增或修正学校需要修改 JSON 数据并重新部署。

## 10. V2 优化需求

### 10.1 目标

V2 版本要从“学校点位清单 + 示意分布图”升级为“基于真实区域和用户位置的教育资源查询工具”。用户不仅能看有哪些学校，还能围绕一个具体生活位置判断周边教育资源密度，并按高新区街道/片区理解学校分布。

### 10.2 功能一：真实地图与高新区区域边界

用户价值：

- 让用户直观看到学校是否位于高新区范围内。
- 减少当前示意图带来的空间误解。
- 为半径查询、街道筛选、路线导航等后续能力打基础。

需求说明：

- 地图展示应参考真实地图信息，优先使用合法可用的地图服务或开源地理数据。
- 页面需要展示成都高新区整体区域边界，并在边界内标注学校点位。
- 高新区边界应区分南区、西区；如数据允许，可继续细分到街道边界。
- 学校点位仍需展示精确/近似状态，近似点位不得包装成精确位置。
- 地图应支持基础缩放、拖拽和点位点击。
- 地图底图和行政边界数据来源必须在页面或文档中标注。

数据需求：

| 数据 | 用途 | 要求 |
| --- | --- | --- |
| 高新区行政边界 | 圈出整体区域 | 需有来源和更新时间 |
| 南区/西区边界 | 区域层级展示 | 若无法获得官方边界，可标注为参考范围 |
| 街道边界 | 街道筛选和分布展示 | 优先获取桂溪、石羊、中和、肖家河、芳草、合作、西园 |
| 学校经纬度 | 点位标注和距离计算 | 需要标记精确或近似 |

风险边界：

- 如果使用高德地图，需要确认 Web 端 Key、服务条款、配额和备案要求。
- 如果使用开源地图，需要确认高新区边界数据的准确性和授权。
- 页面应持续提示：地图用于便民参考，不代表官方学区划片边界。

验收标准：

- 地图能展示高新区整体区域轮廓。
- 66 个校区均能在地图上显示。
- 点击学校点位可联动学校详情。
- 近似点位在详情中仍展示“待精确坐标核验”等状态。
- 页面能说明地图边界和底图数据来源。

### 10.3 功能二：基于位置的周边学校查询

用户价值：

- 用户可以从实际居住、租房、购房或通勤位置出发，查看周边学校资源。
- 比单纯按学校名单查阅更贴近日常决策。

首期示例：

- 默认示例位置：高新区桂溪街道香月湖。
- 默认半径：5 公里。
- 查询结果：展示半径范围内小学、初中和一贯制学校。

需求说明：

- 用户可以输入地点名称或地址作为中心点。
- 系统将地点解析为经纬度，并在地图上展示中心点。
- 用户可以选择查询半径，首期至少支持 5 公里。
- 地图上展示半径圆或覆盖范围。
- 学校列表切换为“周边结果”视角，展示学校名称、学段、性质、街道/片区、地址和距离。
- 距离默认按直线距离计算；如后续接入路线服务，可扩展步行/驾车距离。
- 周边结果应继续支持学段、性质、区域或街道筛选。

推荐交互：

- 搜索栏支持输入“香月湖”“桂溪街道香月湖”或完整地址。
- 半径控件提供 1 公里、3 公里、5 公里、10 公里快捷项。
- 结果列表默认按距离从近到远排序。
- 用户点击结果列表中的学校，地图定位到学校点位并打开详情。
- 当地址无法解析时，展示明确提示，不清空当前已选位置。

数据与算法：

| 项目 | 说明 |
| --- | --- |
| 中心点坐标 | 来自地点搜索或预设位置 |
| 学校坐标 | 来自当前学校数据 |
| 距离计算 | 首期可使用经纬度球面距离计算 |
| 半径筛选 | 学校到中心点距离小于等于用户选择半径 |
| 排序 | 默认按距离升序 |

风险边界：

- 地点解析依赖地图服务或地理编码服务，可能存在配额、费用和误差。
- 近似学校点位会影响距离计算准确性，结果中需提示“部分距离基于近似点位”。
- 半径范围不是入学资格范围，也不是划片范围。

验收标准：

- 用户能以“桂溪街道香月湖”为中心查看 5 公里范围内学校。
- 地图显示中心点、半径范围和范围内学校。
- 结果列表展示学校到中心点的距离。
- 用户能切换小学/初中、公办/民办筛选。
- 无结果时展示空状态和调整半径提示。

### 10.4 功能三：按街道/片区划分浏览

用户价值：

- 用户可以从“我关注哪个街道”出发，理解街道内学校资源。
- 对比不同街道的小学、初中、公办、民办资源数量。

需求说明：

- 增加街道/片区维度的筛选入口。
- 首期街道/片区范围基于当前数据字段：
